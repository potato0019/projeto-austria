# Aplicativo Mobile — Áustria

Aplicativo inicial em React Native com Expo Router.

## Como executar

1. Instale o Node.js LTS.
2. Abra esta pasta (`mobile`) no VS Code.
3. No terminal, execute `npm install`.
4. Execute `npx expo start`.
5. Leia o QR Code com o Expo Go no celular.

A tela mobile já contém as seções principais do projeto e usa imagens locais.
No momento, os textos do aplicativo estão no próprio `app/index.tsx`; a conexão com o MySQL/PHP deve ser feita por uma API para que desktop e mobile compartilhem os mesmos conteúdos.
