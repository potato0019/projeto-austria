# Projeto Áustria

Site informativo desenvolvido como projeto escolar sobre a Áustria.

## Tecnologias utilizadas

- HTML
- PHP
- Tailwind CSS
- JavaScript
- Supabase

## Sobre o projeto

O site apresenta informações sobre a cultura, história, tradições, lendas e curiosidades da Áustria.

Também possui um painel administrativo para gerenciamento de textos e imagens.
